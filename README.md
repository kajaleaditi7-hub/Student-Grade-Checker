# 🎓 C++ Grade Checker

A simple C++ program that checks a student's marks and displays their grade using if-else statements.

## 📊 Grading System

| Marks | Grade |
|---|---|
| 90+ | A |
| 80-89 | B |
| 70-79 | C |
| 60-69 | D |
| 40-59 | E |
| Below 40 | F - Failed |

## 💻 Example

```text
Enter your marks: 85
Grade: B
